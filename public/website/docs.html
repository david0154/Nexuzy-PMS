Welcome to Nexuzy PMS

Nexuzy PMS is a local-first operating system for independent hotels, guest houses and restaurants. It joins the front desk, reservations, restaurant service, billing and the back office into one connected workspace — with the hotel’s database stored on the hotel’s own computer.

The short version

  1. Install the appRun the Windows Setup EXE, use a macOS/Linux package, or start it from source or Docker.
  2. Complete the wizardAdd the property, tax and banking details, then create the first administrator account.
  3. Run the shiftTake bookings, check guests in, serve the restaurant and settle folios from the same guest record.
  4. Back up and closeExport a portable .nxp backup and use Reports → Profit & Loss for the day or month.

New to the app?

Do the first-run setup with the owner or manager present. Use a real property name, correct tax rates and a password that is stored safely — these become the foundation for every bill and report.

Quick start

Choose the installation route that matches the computer that will host the property. The Windows installer is the simplest path for a front-desk PC.

Before you begin

  • Hotel / property name and address
  • Contact phone and email
  • GSTIN, if registered
  • Bank account, IFSC and UPI ID
  • Room and restaurant GST rates
  • Administrator name and password
  • Hotel logo (optional)
  • A backup drive or folder

Windows installer — no Node.js required

  1. Run the Setup EXEUse Nexuzy-PMS-Setup-1.2.0.exe from the release bundle.
  2. Open the shortcutThe installer creates Desktop and Start Menu shortcuts and carries its own runtime.
  3. Complete the wizardThe app opens on the first free local port; the default is 5000.
Default Windows location
%LOCALAPPDATA%\Programs\Nexuzy PMS
Upgrades are data-safe

Upgrading keeps the data\ folder. Uninstalling removes the app only; the database, uploaded logo and backups stay in place. Take a backup before any major change.

From source

Windows · source checkout
install.bat
start.bat
Any OS with Node.js 18.17+
npm install
npm start

Linux & macOS

Terminal
chmod +x install.sh start.sh
./install.sh
./start.sh

Linux packages need a 64-bit glibc system. macOS packages are available for Apple Silicon and Intel. The app is unsigned, so use right-click → Open on first launch if Gatekeeper blocks it.

Docker

Terminal
docker compose up -d

Open http://localhost:5000, then complete the same first-run wizard. For a hosted server, set a strong administrator password and protect the host and network before allowing access.

Port already in use?

Nexuzy tries ports 5000–5009 when the default is occupied. The actual port is written to data/runtime.json and the launcher log. Two installations can therefore run side by side.

First-run setup

On a fresh install, Nexuzy opens a two-part setup wizard. It creates the hotel, the first admin account and a clean starter catalogue. No demo bookings are inserted.

Step 1 — property profile

  1. Hotel / property nameThis appears on the dashboard, confirmations and printed documents.
  2. Property codeA short code such as GHP-17; keep it consistent with internal records.
  3. Contact phone and emailUsed on guest-facing documents and as a fallback for administrator email.
  4. Address, city, state and countryPrinted on tax invoices; enter the registered address.
  5. GSTIN / tax IDOptional at this stage, but required on Indian GST invoices. Add it before issuing tax invoices.
  6. Hotel logoOptional PNG/JPG/WebP. Large images are resized automatically; the logo can be changed later in Settings.

Step 2 — operations and ownership

  • Bank name, account number, IFSC and branch — printed on invoices for bank transfers.
  • UPI ID and payee name — shown on bills and confirmations where configured.
  • Room and restaurant GST percentages — defaults are 12% and 5%; set the rates that apply to your property.
  • Currency symbol — defaults to ₹, change it if your property uses another currency.
  • Administrator full name, username, email and password — these credentials open the first admin session and can create staff accounts later.
Protect the administrator account

Use a unique password and store it in a password manager. The admin account can change tax settings, export or restore the database, manage staff and uninstall the app.

Finish and sign in

After setup, the login screen appears. Sign in with the master administrator account. The dashboard starts with zero dummy bookings, so you can add real rooms, staff and menu items at your own pace.

Sign in & roles

The desktop shortcut starts the local server and opens Nexuzy in its own app window. If the app is already running, it reuses the existing server.

Signing in

  1. Open the Nexuzy PMS shortcutOr open the local URL printed by the launcher, usually http://localhost:5000.
  2. Enter the username and passwordUse the administrator credentials created during setup, or a staff account created in Settings.
  3. Check the headerThe property name, business date, system status and signed-in user show at the top of every screen.
  4. Sign out when leaving the deskUse the Sign Out button in the top-right corner, particularly on shared or LAN devices.

LAN mode is opt-in

Remote devices cannot reach the server until an administrator enables LAN mode in Settings → Local Network. Each staff member should use their own account so sessions can be revoked individually.

Dashboard

The dashboard is the shift’s shared answer to “what is happening right now?” It combines room occupancy, arrivals, restaurant activity, collections and the net position.

Reading the cards

  • Occupancy rate — occupied rooms against room inventory, with the count underneath.
  • Available rooms — sellable rooms now, including a clean-ready count.
  • In-house guests — active checked-in stays, not bookings.
  • Today’s arrivals — expected arrivals for the current business date.
  • Restaurant orders — live orders and occupied tables.
  • Today’s collections, expenses and net — cash/card/UPI receipts, recorded operating costs and the difference.

The room rack

The colour key is deliberate: green is available, violet is occupied, amber is dirty and red is out of order. Click a room for its quick stay detail, folio or housekeeping action.

Start-of-shift routine

  • Confirm the business date
  • Review arrivals and departures
  • Check dirty and out-of-order rooms
  • Review open folio balances
  • Check today’s collections
  • Clear any unread update banner

Front desk

Front Desk & In-House Stays is the operational heart of the hotel: who is in, who is arriving, what they owe and what happens next.

Check in an arrival

  1. Find the bookingUse the arrival row or search by guest name, room or stay reference.
  2. Assign a roomChoose a ready room of the booked type. The deposit paid is visible before check-in.
  3. Confirm the guestCheck phone, dates and rate, then use the Check In action.
  4. Open the folioRoom charges and any restaurant postings continue on the guest’s folio.

Walk-ins, moves and departures

  • Walk-In Immediate Check-In creates a stay without a prior booking; capture the guest and payment details.
  • Room moves keep the same stay and folio, so the guest’s history stays intact.
  • Departures should be settled before checkout. Review the folio balance and generate the invoice from the folio.
  • Extensions change the expected departure and recalculate the stay; use the booking change flow when the rate or dates change.
Search before creating

A quick search can prevent a duplicate guest or a second room assignment. If a guest has stayed before, keep the same record where possible.

Reservations

Reservations protect future inventory. Nexuzy checks room availability, keeps confirmation documents and carries the booking into the front desk on arrival.

Create a booking

  1. Open New ReservationStart from Reservations, or use the dashboard shortcut.
  2. Enter the guest and contactName and phone are the minimum; add email if confirmations are sent.
  3. Choose the stay dates and room typeThe booking must have a valid room type and rate. Do not assign a specific room unless the property’s workflow requires it.
  4. Record the depositAdd an advance if taken; the payment is written to the advance ledger.
  5. Confirm and issue the documentDownload or share the booking confirmation. The booking appears in today’s arrivals on the arrival date.

Changes, cancellations and groups

  • Reschedule or extend — update dates and review the rate difference before confirming.
  • Cancel — record the reason and any refund; the audit trail keeps the original booking.
  • Group bookings — use Group Bookings for staggered groups where different rooms arrive and depart on different dates under one master booking.
  • Confirmations — booking documents can be downloaded as PDF and shared to WhatsApp.
Double-booking guard

Do not manually create a second overlapping reservation for the same room. If the system blocks a date, review the existing booking and use reschedule or room move instead.

Rooms & housekeeping

Room types define what you sell; room inventory defines what is physically available. Housekeeping status tells the front desk what can be sold right now.

Create a room type

  1. Open Rooms & HK → Manage Rooms & TypesCreate the category guests will book, such as Standard or Deluxe Suite.
  2. Set the code, base rate and occupancyThe base rate is the starting nightly price; extra adult charges can be configured separately.
  3. Add room inventoryCreate the physical rooms and assign each one to a room type, floor or building.
  4. Review taxRoom GST is applied to room charges; confirm the rate used on your invoices.

Housekeeping status

StatusMeaningFront desk action
AvailableClean and ready to sell.Can assign to an arrival or walk-in.
OccupiedA guest is currently in-house.Do not reassign; use a room move if needed.
DirtyDeparted or needs servicing.Ask housekeeping to clean before selling.
Out of orderPhysically unavailable.Remove from sale and note the reason.

Keep the room rack current throughout the shift. A clean room that is still marked dirty costs a sale; an occupied room marked available creates a double-booking.

Restaurant menu

The POS is only as good as its menu. Set categories, dishes, prices, tax and preparation station once; the order screen and kitchen display use them everywhere.

Menu setup

  1. Create categoriesUse groups your team recognises: Food & Dining, Beverages, Breakfast, Bar, Bakery.
  2. Add dishesSet the display name, selling price and the tax rate that applies.
  3. Choose the stationKitchen, bar or bakery routing determines where the kitchen display shows the item.
  4. Mark veg / non-veg and availabilityHide sold-out items instead of deleting them; history and reports remain intact.
Change prices with care

A menu price change affects new orders. Existing orders keep the price captured when they were created, so always review open bills before a price update.

Table bookings & advances

Take a restaurant reservation with an advance, reserve a table and issue a receipt before the guest arrives. The booking is confirmed as soon as the advance is recorded.

Create a table booking

  1. Enter guest and phoneUse a reachable phone number so the team can confirm or adjust the booking.
  2. Choose date, time and guestsPick a table if one is available, or leave it for the floor team to assign.
  3. Take the advanceSelect cash, UPI, card, bank transfer or net banking and record the reference.
  4. Confirm and shareThe booking is confirmed automatically; download or share the receipt on WhatsApp.

During service

  • Seat the party when they arrive and open a POS order for the table.
  • Complete the booking after service; the table returns to the floor plan.
  • Cancel with a reason. Refunds should be approved and recorded, not handled outside the system.

Restaurant POS & kitchen display

Run dine-in, takeaway and room service from the same menu. Send food to the kitchen, settle a table separately, or post the charge to a guest’s folio.

Take an order

  1. Choose the order typeDine-in, takeaway, room service or another configured type.
  2. Select the table or roomFor room service, choose the in-house room so the charge can be posted to the right folio.
  3. Add dishes and quantitiesReview notes and modifiers before sending the order to the kitchen.
  4. Send the KOTThe kitchen display receives the items and their station; the floor team tracks preparation.
  5. Settle or postTake payment for a restaurant bill, or use Post to Room to add the charge to the guest’s folio.
Restaurant tax

The restaurant GST rate is configured during setup (5% by default). Menu items can carry their own rate where the property needs a different treatment. Always review a bill before handing it to the guest.

Guest folios

A folio is the single financial story of a stay: room charges, restaurant postings, payments, deposits and the balance still due.

Work the folio

  1. Select the room or guestOpen the folio from Billing & GST Folios or from the in-house stay.
  2. Post a chargeAdd room rent, restaurant orders or a manual charge with the correct department and tax.
  3. Record a paymentCapture cash, card, UPI or another mode, with a reference where applicable.
  4. Review the balanceTotal charges minus recorded payments and deposits must be zero before final checkout.
  5. Generate the tax invoiceIssue the final document after the folio is settled and the bill is confirmed.
Do not close an open balance

If the guest is paying later, leave the folio open and record the arrangement. Closing without payment distorts collections and the day’s reports.

GST invoices

Nexuzy produces printable A4 tax invoices with the property’s GSTIN, HSN/SAC codes, tax split, bank/UPI details and the hotel logo.

Before issuing a tax invoice

  • Property legal name and address are correct
  • GSTIN is entered in Settings
  • Room and restaurant tax rates are correct
  • Folio charges and payments reconcile
  • Invoice number sequence is uninterrupted
  • Guest name and address are complete

Download, print or share

  1. Generate from the settled folioThe final invoice is locked to the folio so it cannot silently change after issue.
  2. Download the PDFThe A4 document is generated server-side and carries the hotel branding and Nexuzy footer.
  3. Share on WhatsAppDownload the PDF first, then attach it to the pre-filled WhatsApp message.
  4. Reprint when neededOpen the folio or invoice history to retrieve the issued document.
Accounting note

Tax rules depend on the property’s registration and jurisdiction. Confirm the configured rates and invoice format with your accountant before the first live tax invoice.

Hotel expenses

Record operating costs alongside revenue so the dashboard’s net figure and the profit & loss report reflect the real property, not just sales.

Record an expense

  1. Choose a categoryUse consistent categories such as salaries, groceries, utilities, maintenance or housekeeping.
  2. Add vendor and amountCapture the date, payment mode and a reference or invoice number.
  3. Save for the periodThe expense appears in the day’s dashboard and the selected reporting period.
  4. Void a mistakeVoid rather than delete so the audit trail preserves the correction.

At month end, export the relevant reports and attach supporting invoices to your accounting records. Nexuzy keeps the operational ledger; your accountant remains the source of statutory filing.

Reports & audit

The reports workspace turns the shift into decisions: revenue by department, GST collected, expenses, profit and a searchable audit trail.

What to review

ReportQuestion it answers
Profit & LossWhat did we earn after tax, what did we spend, and what is left?
Revenue by DepartmentWhich areas — rooms, restaurant, service — are carrying the property?
GST Collection BreakdownHow much tax was collected at each rate, and what is the taxable value?
Expenses by CategoryWhere is the operating money going?
System Audit TrailWho created, changed, voided or generated each financial document?

A simple reporting rhythm

  • Every shift — check collections, open folios and any failed or voided actions.
  • Every day — close the business date, review the day’s net and back up the database.
  • Every week — compare revenue by department against expenses and occupancy.
  • Every month — export the P&L and GST summary for accounts, then store the backup off the hotel PC.

Settings & backup

Settings is the administrator’s control room: property identity, staff access, backups, email, LAN, desktop shortcut, updates and uninstall.

The safe backup routine

  1. Open Settings & BackupGo to the Portable .nxp Package section.
  2. Export & Download .nxp PackageNexuzy creates a verified, checksum-protected snapshot of the database.
  3. Store a copy off the hotel PCUse a password-protected drive, a trusted cloud folder or the Google Drive integration.
  4. Test the restore on a spare machineNever wait until an emergency to discover that the backup routine is broken.
Restore replaces operational data

Restoring a backup is a destructive recovery action for the current database. Export a fresh backup first, and restore only during a planned maintenance window.

Other settings

  • Property details — legal name, address, GSTIN, bank, UPI, tax rates, logo and contact details.
  • Staff users & access — add staff, assign roles, deactivate leavers and reset passwords.
  • Google Drive — connect a folder ID and run a manual sync; keep the backup routine under review.
  • SMTP mail — configure the hotel mailbox and send a test email before relying on automatic mail.
  • Desktop shortcut — recreate the one-click launcher if the original is lost.
  • About, Support & Uninstall — version, developer, donation link, update controls and the guarded uninstall action.

LAN mode

LAN mode lets staff phones, tablets and a second desk use the host computer’s live database over the private Wi-Fi. It is off by default and must be enabled by an administrator.

Enable it

  1. Open Settings → Local NetworkEnable LAN access and choose the port if the default needs changing.
  2. Connect devices to the same private networkUse the host’s LAN URL or the provided QR code. Do not use guest Wi-Fi isolation.
  3. Allow the firewall ruleOn Windows, run enable-lan-firewall.bat once as Administrator if phones cannot connect.
  4. Create individual staff accountsEach person signs in separately so a device session can be revoked without changing everyone’s password.
Private network only

LAN mode uses plain HTTP for local convenience. Use it only on a trusted private network, never forward the port from the router, and disable LAN access when it is not needed.

If a device cannot connect

  • Confirm the host and device are on the same Wi-Fi or wired LAN.
  • Use the exact URL shown in the app, including the port (for example http://192.168.0.106:5000).
  • Check that the host firewall allows the port on private networks.
  • Disable guest-network isolation or “AP isolation” on the router.
  • Review active sessions in Settings and revoke any device that should no longer have access.

Updates & uninstall

Installed builds check GitHub for a newer release once a day. Administrators can check immediately from Settings → About, Support & Uninstall.

Update safely

  1. Export a fresh .nxp backupDo this before any update, even a small one.
  2. Read the release noteConfirm the version and any migration or configuration steps.
  3. Download the installer for this platformWhen published, Nexuzy verifies the SHA-256 checksum before starting the update.
  4. Run the installerUpgrades preserve the data folder. Reopen the app and sign in after the update.

Uninstall

Uninstall is administrator-only and requires typing UNINSTALL in the confirmation dialog. It removes the application; the hotel database, uploaded logo and backups remain in the data folder.

  • Windows data — %LOCALAPPDATA%\Programs\Nexuzy PMS\data
  • Linux data — the installed app’s data/ folder
  • macOS data — ~/Library/Application Support/Nexuzy PMS
Uninstall is not a backup

Take a portable backup and copy it off the computer before uninstalling. If the computer itself is being retired, the data folder must be copied first.

Troubleshooting

Start with the symptom, then check the simplest local cause. Most issues are port conflicts, stale browser pages, firewall rules or a backup that needs restoring.

SymptomWhat to check
App does not openCheck data/launcher.log in the install folder. Confirm the port is free and the browser/runtime is present. Try the Start Menu shortcut.
“Port 5000 is already in use”This is handled automatically: Nexuzy tries 5001–5009. Read data/runtime.json for the actual port. Stop only the old PMS process if you intended to replace it.
Endpoint not found / old About panelThe browser may be connected to an older server process. Restart the PMS server, then hard-refresh with Ctrl+F5.
Login does not workCheck Caps Lock and the username. Ask an administrator to reset the staff password in Settings. If the only admin password is lost, restore a backup or contact support.
Phones cannot reach the deskEnable LAN mode, use the exact LAN URL, allow the firewall rule and disable router client isolation.
PDF does not downloadAllow downloads/pop-ups for the local URL and try again. The PDF is generated server-side from the settled folio.
Data looks wrong after a testDo not keep editing. Export the current state, then restore the last known-good .nxp backup.
Update banner is quietInstallations check once a day; administrators can use Check for updates in About. Offline hotels will simply see no newer release.

Useful files

  • data/nexuzy.db — the live SQLite database. Do not edit it by hand.
  • data/runtime.json — the port, local URL, LAN URL and process ID of the running server.
  • data/launcher.log — startup, port fallback and browser-window messages.
  • backups/ — exported .nxp packages and operational backups.
Still stuck?

Include the app version, operating system, the exact error text and the relevant log lines when contacting support. Never send a live database or administrator password in a public issue.
