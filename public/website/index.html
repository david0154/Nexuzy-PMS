From first key to night audit

A quieter shift, start to finish.

Nexuzy is arranged around the natural rhythm of a property. Each workspace hands the guest, the room and the money to the next person cleanly.

  • One guest record follows the stay from booking to folio.
  • Restaurant orders can live on their own bill or post to the room.
  • Every payment, void and invoice is written to the audit trail.

Go live in minutes

Bring your property online.

Use the Windows Setup EXE for a no-Node install, or run the source or Docker workflow. First launch opens a guided setup — no demo data.

Full installation guide
Windows No Node.js

Run the Setup EXE, then open the Desktop shortcut. The installer carries its own runtime and keeps your data on upgrade.

Windows setup steps
macOS Apple Silicon + Intel

Extract the archive, run the install command and launch the app. Data lives in Application Support and survives removal.

macOS setup steps
Linux glibc x64

Use the self-extracting .run or .tar.gz package. Shortcuts and a safe upgrade path are included.

Linux setup steps
Source / Docker npm · compose

For a server, a custom port or a development setup, install dependencies and run npm start, or bring it up with Docker Compose.
