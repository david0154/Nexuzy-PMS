# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in Nexuzy PMS, please do not disclose it publicly via GitHub issues.
Instead, send an email directly to our lead developer:

**Email**: [david@nexuzy.in](mailto:david@nexuzy.in)  
**General Contact**: [info@nexuzy.in](mailto:info@nexuzy.in)

Please include:
- A description of the vulnerability
- Steps or proof-of-concept to reproduce the issue
- Potential impact and mitigation recommendations

We appreciate your responsible disclosure and will respond within 48 hours.
